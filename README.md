# Carnet de recettes

Application web en JavaScript pour consulter et rechercher des recettes avec l’API DummyJSON via Axios.

- Recherche par nom et affichage des résultats.
- Formulaire d’ajout avec validation côté navigateur.
- Suppression avec confirmation et gestion des erreurs.

## Démarrage

```bash
npm ci
npm run dev
```

DummyJSON simule les ajouts et les suppressions. Ces modifications ne sont pas persistées par l’API. Le projet utilise Vite et Tailwind CSS.
